G-Spark growth plan

The features are planned into layers, so you can launch them gradually.

Built to grow
LAYER 1 · INCLUDED🎮 Core arcade

Responsive landing page, searchable game cards, six playable mini-games, category filters.

LAYER 2 · INCLUDED🔎 Discovery

Collection search and a web-search shortcut for discovering more games online.

LAYER 3 · INCLUDED♥ Player basics

Local favourites, a nickname, and lightweight browser stats.

LAYER 4 · READY TO PLAN🖼 Game library upgrade

Game thumbnails, featured picks, curated collections, and a larger catalog.

LAYER 5 · READY TO PLAN🌐 Online game integrations

Add approved game embeds or partner links after checking each game's permissions and mobile compatibility.

LAYER 6 · READY TO PLAN☁️ Accounts & leaderboards

Real accounts, cloud saves, verified scoreboards, and admin tools need a backend and security setup.

The roadmap is a product plan, not a claim that every future feature is already connected. Online accounts, cloud saves, and global leaderboards are not enabled in this static version.

A little spark goes a long way ✨

G-Spark Arcade is a starter game hub. Mini-games run in the browser, and saved player information stays on this device. Web search helps visitors discover external sites but does not download or host their games. Use trusted websites and never share personal information on unfamiliar sites.

No account is required. Nickname, favourites and game stats are stored locally in this browser. Read our privacy notice.
