G-SPARK ARCADE — FREE PUBLISHING PACKAGE

Included files
- index.html: responsive arcade homepage and six playable mini-games
- privacy.html: basic privacy notice for the current static prototype
- favicon.svg: browser tab icon
- robots.txt: allows search crawlers to access public pages

FEATURES
- Search and category filters for six mini-games
- Tic-Tac-Toe, Memory Match, Spark Tap, Number Quest, Rock Paper Scissors and Colour Dash
- Browser-local favourites, nickname and simple stats
- Web-search shortcut
- Mobile-friendly layout, SEO metadata, social preview metadata and basic WebSite structured data

IMPORTANT LIMITS
This is a static front-end site. It has no server, real accounts, cloud saves, global leaderboard, online admin dashboard, analytics, or automatic game imports. Local browser storage stays on the visitor's device. Search engines decide when and whether to index the website; metadata does not guarantee rankings or immediate appearance in search results.

PUBLISH FREE USING GITHUB PAGES
1. Sign in or create an account at https://github.com/.
2. Create a NEW PUBLIC repository named gspark-arcade (or another name you prefer).
3. Upload all four files from this folder to the repository's top/root level: index.html, privacy.html, favicon.svg and robots.txt.
4. Open the repository's Settings, then Pages.
5. Under build/deployment, choose Deploy from a branch. Select branch main and folder /(root), then save.
6. Wait for GitHub Pages to publish. The URL will usually look like https://YOUR-USERNAME.github.io/gspark-arcade/ . Replace YOUR-USERNAME with your actual GitHub username; do not publish this example URL as if it were real.
7. Open the published URL on a phone and computer. Test each game, search, filters, favourites and privacy page.

SEARCH ENGINE DISCOVERY
After the real public URL is live, you can add the site to Google Search Console and use its URL inspection/request-indexing tools. Search indexing is not instant or guaranteed. Do not submit the placeholder URL.

FREE HOSTING NOTES
GitHub Pages offers free static hosting for eligible public repositories. It does not run a backend/database. The site remains online while the repository/account and hosting service remain in good standing; no host can promise permanent uptime. A custom domain is optional and generally costs money.
